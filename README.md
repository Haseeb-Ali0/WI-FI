
# 📡 WI-FI Checker

**WI-FI Checker** is a beginner-friendly Python terminal tool for checking internet connectivity, download speed, latency, and public IP address.

It features a hacker-style terminal interface with colored text, a simple menu, and real-time network diagnostics.

## ✨ Features

- 🌐 **Internet Connection Check** — Checks whether the internet is reachable.
- 💻 **System Information** — Displays operating system, Python version, and computer details.
- 🚀 **Internet Speed Test** — Measures download speed in Mbps.
- 🌍 **Public IP Check** — Displays your public IP address.
- 🎨 **Hacker-Style Interface** — Colored terminal output and a custom ASCII banner.
- 🐍 **Python 3** — Uses Python's standard library without extra packages.


## ⚙️ Requirements

* Python 3.x
* Basic Networking Knowledge
* Operating System:

  * kali Linux



## ⚠️ Limitations

- Download speed results depend on your internet connection and the test server.
- A server may return HTTP 403 or become unavailable.
- TCP latency is not the same as ICMP ping latency.
- The current version measures download speed only; it does not measure upload speed.
- The tool does not currently save reports to a file.
